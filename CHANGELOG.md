# Changelog

All notable changes to the classics pack are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions are calendar versions
`YYYY.MM.N`.

## [Unreleased]

## [2026.11.2] - 2026-11-12

Requires bentwire 0.1.0 or later. 61 characters; all but the two Greetings Workshop actors
are unchanged (regenerated byte-identically). bentwire 0.1.1 loads this pack as before; the
new labels show with the bentwire release after 0.1.1.

### Fixed

- `rocky-greetings-act` and `rocky-earlygreetings-act` showed coloured noise: they were
  converted with the Office palette, but they index a Greetings Workshop palette that no
  source file carries. Their colours now come from `rocky-97`, which shows the same
  pictures in the Office palette (`palette-from` in `options.txt`, bentwire A-CONV-7). The
  colours are those of the Office variant, not the lost original palette.

### Changed

- Every character is shown with its product: "Clippit (Office 97)", "Merlin (Microsoft
  Agent 1.5)", "Al (Microsoft Agent 1.5, third-party)". No two characters share a label in
  `bentwire characters`, the gallery, the tray menu or the README gallery table.
- `pack.toml` holds the per-id labels where the files cannot tell (`[labels.<id>]`, name
  and product) and the product order of the README gallery table; it replaces
  `gallery.tsv`, and `regenerate.sh` no longer writes `pack.toml`.
- `dolphin-97` is listed as Kairu and `offlady-97` as Saeko-sensei (both files only have a
  Japanese entry, which left the name empty); `tutor-act`, whose file calls it "Unnamed",
  is listed as Tutor (My Personal Tutor).
- `tofflogo-97`, the still Office Logo, is told apart from `logo-97` as "Office 97,
  static"; `rocky-earlygreetings-act` from `rocky-greetings-act` as "Greetings Workshop,
  early version". Both Greetings Workshop files name their dog Rover, so the names stay;
  the ids keep the file stem ROCKY (A-ID-1), so saved selections keep working.

## [2026.11.1] - 2026-11-11

Requires bentwire 0.1.0 or later. 61 characters.

### Added

- Four characters: `genie`, `peedy` and `robby` (Microsoft Agent 2.0, from their complete
  `.acs` files) and `ozzar-15` (Agent 1.5, third-party, all 106 animations).
- `gallery/<id>.png`: every character in its rest pose at 1x on a transparent background,
  made by bentwire's `scripts/gallery.sh`, byte-identical on every run; the README shows
  them as a grid with name, id, family and source product.
- Screenshots and animated GIFs on a KDE Plasma desktop.
- A note to Microsoft at the top of the README.

### Changed

- `regenerate.sh` and `sources.sh` take the original files from `BENTWIRE_SOURCES`, one or
  more directories with your own copies in any layout, found by file name and verified by
  SHA-256. This replaces the two variables of 2026.11.0. `CONTENTS.md` names source files
  only.
- The Agent 2.0 web characters (ACF + ACA) and `ZVISIBLE.ACT` are no longer in the source
  list; `CONTENTS.md` says why.
- The README follows a new layout: header, note, gallery, characters, install, regenerate,
  screenshots.
- The 57 characters of 2026.11.0 are unchanged (regenerated byte-identically).

## [2026.11.0] - 2026-11-11

First release. Requires bentwire 0.1.0 or later.

### Added

- 57 characters converted into the bentwire format: 12 Agent 2.0, 9 Agent 1.5, 15 Office 97,
  18 Microsoft Bob and 3 other ACT actors.
- The Office XP balloon theme `balloon-themes/office`, from `OBALLOON.DLL` 10.0.2607.
- `regenerate.sh` and `sources.sh` to rebuild the pack byte-identically from the original
  files; `CONTENTS.md` with the source of every character and every excluded source.
- Screenshots of bentwire with these characters.
